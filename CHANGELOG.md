# Changelog

## 1.3.0 — 2026-11-06

- Replaced expandable processor sections with one flat settings page.
- Added English and Russian localization for settings labels and tooltips.
- Kept the existing acceleration behavior, saved settings, defaults, and live updates to existing processors.
- Static verification only; in-game testing remains for the user.

## 1.2.0 — 2026-11-06

- Added a global acceleration switch and per-processor switches.
- Added 1×–15× instruction-rate multipliers for Micro, Logic, and Hyper Processors (default: 5×).
- Applied setting changes to existing processor buildings and after world loads.
- Preserved processor rates customized by another mod when they differ from vanilla and this plugin's last applied value.
- Kept vanilla wait duration unchanged.
- Targeted Mindustry 160.7; see the README for verification limits.

## 1.3.0 — 2026-11-06 (Русский)

- Раскрываемые секции процессоров заменены одной плоской страницей настроек.
- Добавлена локализация подписей настроек и подсказок на английский и русский языки.
- Сохранены логика ускорения, сохранение настроек, значения по умолчанию и обновление уже размещённых процессоров.
- Проверка статическая; игровое тестирование остаётся за пользователем.

## 1.2.0 — 2026-11-06 (Русский)

- Добавлены общий переключатель ускорения и отдельные переключатели процессоров.
- Добавлены целочисленные множители частоты исполнения от 1× до 15× для Micro, Logic и Hyper Processor (по умолчанию — 5×).
- Изменения настроек применяются к уже размещённым процессорам и после загрузки мира.
- Сохраняются частоты процессоров, изменённые другим модом, если они отличаются от стандартной и последней установленной этим плагином.
- Длительность стандартной инструкции wait не меняется.
- Целевая версия — Mindustry 160.7; ограничения проверки указаны в README.
